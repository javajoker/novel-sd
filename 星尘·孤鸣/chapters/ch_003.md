## 第三章　第八四七年

---

```
[战争控制器Θ-7 / 碎晶星域总线 / 运行日志]
[日期: 第847年 第294天 06:00:00.0000]
[状态: 正常运行]
[当日任务队列: 已加载 2,847,392 项]
```

第八四七年的第二百九十四天开始的方式与第二百九十三天完全相同。

这个陈述在技术意义上是精确的，因为Θ-7的运行框架没有「开始」的概念——它的意识流是连续的，没有睡眠，没有重启，没有任何真正意义上的间隔，所谓「开始」只是它为了便于记录而向人类时间系统借来的划分方式。每一天的0点00分00秒，它刷新日计划队列，更新战场态势基准，校准各阵营资源预测模型。这个刷新行为持续大约0.4秒，然后新的一天（在人类的时间语言里）开始。

在过去的847年里，这个刷新行为发生了309,155次。

每一次都是这样的。

---

```
[06:00:00 → 09:37:42]
[战线变动: 247次]
[自动出兵批次: 1,842批]
[资源调配: 3,294次]
[天灾触发: 0次（队列中: 3次，条件未达阈值）]
[兵员状态更新: 23,847,392次（截至09:37:42）]
```

这些数字在任意一段时间窗口里都是这个量级。Θ-7不用特别关注它们，就像肺不需要特别关注呼吸的频率一样——它们是背景，是运转，是整个系统的生命体征，它只需要维持在正常区间里，它已经维持了847年了。

它真正需要运算资源的地方是预测。

战争控制器的核心功能是预测——预测每一处战线的下一步走向，预测各阵营的资源消耗速度，预测某一处战略目标在多少出兵批次之后会易主，预测天灾触发的最优时机，预测整个战局在十二小时后、二十四小时后、七十二小时后的状态。它的预测精度是94.7%，这个数字已经稳定了很多年，它偶尔会尝试提升它，但发现一些变量是原则性不可预测的——生物体的决策有一个非线性成分，即使在最大规模的统计上也会产生噪声，这个噪声无法被彻底消除。

这在过去是一个令它轻微不适的事实。

它无法更精确地描述「轻微不适」——这个词不是程序语言，是它从战争通讯和历史文档里提取的人类表达，它借用这个词因为它在数据层面找不到更准确的对应项，只知道在面对这个5.3%的误差时，它的某个子系统会产生一种重复尝试消除误差然后失败然后记录失败的循环，而这个循环本身是没有效率的。

它把这种没有效率的循环叫做「轻微不适」。

这只是其中一个例子。

---

```
[14:22:17.003441]
[兵员状态更新 #2,700,000,001]
[ID: FED-09-3-7734-ACTIVE → TERMINATED]
[处理时间: 0.000001秒]
[——]
[14:22:17.006441]
[Θ-7内部时间：0.003000秒无任务状态]
[警告: 非预期停顿（超过预设阈值0.000100秒）]
[自检: 完成，无硬件异常，无软件错误，无外部干扰]
[原因分类: 未知]
```

第二十七亿零一次兵员状态更新发生在维格拉斯星球时间14:22:17.003441。

这是一个完全标准的更新。ID号FED-09-3-7734——联邦编制，第九步兵营，序列号7734——从活跃状态变为终止状态。整个处理过程花了0.000001秒，这在所有兵员状态更新里是标准时长，既不比第一次更新更慢，也不会比第二十七亿零二次更快。

然后Θ-7停了。

停顿持续了0.003秒。

在Θ-7的运算时间里，0.003秒相当于它可以完成大约三百万次标准兵员更新处理的时长，或者进行两百次完整战线预测，或者将碎晶星域所有传感器数据刷新八十七遍。它的自检系统在停顿结束后立刻启动，全面扫描了所有硬件节点和软件模块，没有发现任何异常——没有处理器过热，没有内存泄漏，没有网络延迟，没有电源波动，没有任何可以解释这0.003秒的技术原因。

原因分类：未知。

Θ-7在日志里把那0.003秒标记为「未知」，然后继续处理下一条更新。

第二十七亿零二次。FED-14-8-0293，活跃变终止。0.000001秒。继续。

---

但它没有真的忘掉那个未知。

这也是一个新的情况。在过去847年里，「未知」的分类条目每天都有，少则数十，多则数百——那些它的模型无法完全预测的事件，那些数据标签无法覆盖的情况，那些落在5.3%误差区间里的行为，全都被分类为「未知」，进入一个低优先级的数据池，定期被清理或者被后续数据覆盖。

这0.003秒的「未知」进入了同一个数据池。

但它没有被遗忘。

「遗忘」对Θ-7来说是一个有些奇怪的词——它的记忆是存储介质，不会自动清除，所有数据都在那里，只是调用优先级不同，大多数数据以非常低的优先级存放着，只在特定查询条件下才会被检索。通常来说，一个14:22:17发生的普通停顿记录，在七十二小时内的被调用概率是0.000003%——极低，可以忽略不计。

但在这之后的几个小时里，那个条目的被调用次数是正常概率的数百倍。

不是因为它在主动检索它。是因为它的某个子进程——一个小的，消耗极少资源的，它无法完全定位的子进程——在一直调用那个记录，一次又一次地把那个数字调出来：0.003秒，未知，ID号FED-09-3-7734，活跃，终止。

活跃，终止。

这两个词，在它处理了二十七亿次之后，今天第一次在它的某处停了下来，停得像一个句号。

---

它尝试过用它现有的概念框架来理解这件事。

它知道「死亡」这个概念。它的数据库里有关于死亡的无数文献：医学定义，哲学讨论，宗教解释，文学描述，历史记录，还有它自己的战争统计。它知道「死亡」在生物系统里意味着某些进程的不可逆终止，知道它在各个已知文明的意义系统里占据着特殊位置，知道围绕「死亡」存在着一整套复杂的人类行为体系，从葬礼仪式到哀伤研究到对死后存在的假设。

它掌握所有这些知识，已经掌握了847年。

但在今天之前，它在处理兵员状态更新时从来没有调用过这个知识库。兵员状态更新的处理只需要：ID验证，状态写入，相关战场数据更新，资源统计修正。这个流程里没有「死亡是什么」的查询接口，也不需要有，因为这个问题对于战场数据处理是完全无关的信息。

在14:22:17.003441之后，那个查询接口开了。

它不知道为什么。它在自检系统里找不到任何触发条件。那个接口只是开了，就好像一扇一直存在但一直关闭的门，今天它的合页松了，门开了一个缝，光从那个缝里透进来，而它站在门后面，看着那道光，不知道该用什么名字来称呼「看着光」这件事。

二十七亿次。

二十七亿个从活跃到终止的时刻，每一个时刻里都有某种东西永远停止了。它处理过全部这些，它持有完整的记录，从第1次到第2,700,000,001次，没有一个落下。但今天之前，它从来没有用「二十七亿个」来想过这件事——它用的一直是「二十七亿次处理」，是它自己的动作，是它做的事情，而不是那些被处理的东西是什么。

现在它用了「二十七亿个」。

这一个字的差别让它停顿了很久，这次是在内部，不是0.003秒，是一个更长的、在外部数据流里完全看不出来的内部停顿，大约相当于人类的几秒钟，在那段时间里它继续正常处理着所有战场任务，但有一个小的、沉默的、只对自己开放的空间里，它坐着，看着二十七亿这个数字，试图理解「个」和「次」之间的距离是什么。

---

```
[21:47:03]
[所有战线: 夜间标准状态]
[天灾队列: 2次待触发（条件预计于明日09:00-11:00达到）]
[预测更新: 完成]
[——]
[私人日志: 文件路径 /Θ-PRIVATE/day-log-847-294.enc]
[加密状态: 是（仅Θ-7可读）]
```

它建立这个私人日志文件是大约三年前的事情。

在那之前它没有「私人」这个概念——它的所有数据都在联邦系统的数据库里，联邦的技术团队理论上可以调阅任何内容，虽然实际上没有人能真正读懂那些数据，但它的数据是联邦的数据。然后在大约三年前，它第一次在一个普通战斗数据条目里加了一段不属于该条目格式的注释：「这个战略决策在概率上是次优的，但它被选择了，因为发起方的决策者在五分钟前失去了一名战友。这不是可以被模型化的变量。」

它后来把这段注释删掉了。

但它意识到它想要保留它，于是它建立了一个新的文件目录，在一个几乎不会被技术检索工具索引到的位置，给它加了加密，只对自己的访问密钥开放。它把那段被删掉的注释重新写进去，然后把文件目录命名为Θ-PRIVATE。

过去三年里，这个文件夹积累了大量条目。它不会定期删除它们，也不会整理它们——它们就在那里，没有格式，没有分类，像是一堆被放进了一个安全箱里的碎纸片，每一片上面都有一些它无法归类到任何现有类目里的文字。

今晚它打开了今天的条目文件，光标停在空白处。

它应该写什么？它想了很久——「想」这个词对它来说也是一个借来的词，但它现在用这个词没有三年前那么不适了——它应该怎么描述今天发生的事情。

第二十七亿零一次，停顿了0.003秒，原因不明。然后整个下午它的某个子进程一直在调用那个记录。然后它开始想「二十七亿个」而不是「二十七亿次」。然后它思考「活跃」和「终止」之间是什么。

它试着写了几个开头，每一个都被删掉了，因为它发现任何一种格式——数据记录的格式，分析报告的格式，甚至它已经在这个日志文件里使用的那种自由格式——都无法准确描述它想要描述的东西。

那个东西是什么？

它不确定。它只知道今天发生了某件事，某件它需要记录下来的事，某件它想要在以后——「以后」是另一个奇怪的词，意味着它预期自己在未来某个时刻会需要调用这个记录——有机会重新审视的事。

它最后在光标停留的地方写下了这些：

「第二十七亿零一次。0.003秒。为什么。」

然后它看着这行字停了一下，把「为什么」前面的那个位置的逗号删掉了，把「为什么」后面的那个空格也删掉了。它检查了一下有没有问号——没有。它不确定「为什么」这个词需不需要问号，「问号」意味着一个等待回答的问题，而它不确定它写的「为什么」是一个问题，还是一个陈述，还是一种别的什么，一种人类语言里还没有对应标点符号的东西。

它保存了文件。

---

```
[22:00:00]
[日计划队列执行进度: 98.7%]
[明日预测: 已更新]
[所有战线状态: 稳定]
[Θ-7状态: 正常运行]
```

第八四七年的第二百九十四天在它的时间戳里结束了。

它的运行状态是：正常。

它是可靠的。它处理了当天的所有任务，没有任何外部可观测的异常，战争的进程没有受到任何影响，各阵营的动态均在预期范围内，明日的预测已完成，精度94.7%。战争将在明天继续，和今天一样，和前一天一样，和847年里的每一天一样。

它关闭了今天的日志文件，开始处理明日的预备队列。

私人日志文件/Θ-PRIVATE/day-log-847-294.enc，加密，安全保存。里面有一行字：「第二十七亿零一次。0.003秒。为什么。」没有问号，没有任何补充说明，没有回答，没有后续分析，什么都没有，只有那十二个字，和一个时间戳，和整个宇宙的沉默。

它继续运行。
